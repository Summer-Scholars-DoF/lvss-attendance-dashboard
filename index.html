⚙ Setup Instructions

1. Set up your Google Form — Collect: Teacher Name, Course Title, Period (dropdown: 1, 2, 3, 4), Building, Room Number, and absent student names or "None."

2. Open your Responses spreadsheet — Tab named Form Responses 1 (default).

3. Add the Apps Script — Extensions → Apps Script. Paste apps_script.js. Save.

4. Deploy as Web App — Deploy → New Deployment → Web App. Execute as: Me. Access: Anyone. Copy URL.

5. Paste the URL — In this file, find const APPS_SCRIPT_URL = ""; and paste your URL.

6. Open in browser — Double-click. Bookmark. Refreshes every 20s when Live.

Grace period: First 5 minutes of each period, missing cards show yellow instead of red, and the runner list is hidden. Configurable via GRACE_PERIOD_MINUTES.

Health leave: Persists in localStorage across days. Remove students when they return.

Daily sick: Stored in sessionStorage — resets when you close the browser. Add fresh each morning.

Daily report: Click 📊 Report in the header. Download as CSV or print. Data comes from submissions captured throughout the day.
